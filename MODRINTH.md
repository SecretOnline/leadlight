# [Leadlight](https://secretonline.co/mods/leadlight)

Create ornate and decorative stained-glass windows.

![A sunset scene painted in glass.](https://cdn.modrinth.com/data/C14yhAkO/images/7dd03ebe81a4c9b5f1e3c0fe02880de33b7d41c0.png)

Fabric releases of this mod require [Fabric API](https://modrinth.com/mod/fabric-api), so make sure it's installed.

## Getting started

### Window Frames

To get started with this mod, you'll need to craft some Window Frames using Iron Nuggets.

![Crafting Large Iron Window Frames](https://cdn.modrinth.com/data/C14yhAkO/images/b438fe0919ad56e639fd6be8fc10ffe75e4058a0.png)

Other frame shapes are made by adding to the Large frames.

![How to craft each type of Window Frame from the Large frame.](https://cdn.modrinth.com/data/C14yhAkO/images/fccd6142a65800a6ea56fe9bda16b61f92ad9d6c.png)

### Cut Stained Glass Panes

Normal Stained Glass Panes are too large to fit inside the Window Frames, so use a Stonecutter to slice Stained Glass Panes into Cut Stained Glass Panes.

You can also craft 4 Cut Stained Glass Panes of the same color back into a normal Stained Glass Pane.

### Placing

Place down your Window Frames, then use Cut Stained Glass Panes in an empty spot to fill it. To remove the glass from a filled spot, use an empty hand instead.

![Ari fills a window](https://cdn.modrinth.com/data/C14yhAkO/images/b1cbb2626c4744fc71ef49f47797fa27e0df3981.png)
